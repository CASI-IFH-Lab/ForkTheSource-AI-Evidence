## What this changes

Adds `dashboard/` — `theme.py` (every colour, label and icon, defined once) and `app.py`
(the page). `streamlit run dashboard/app.py` renders any `Ledger` JSON, fully offline,
with no key and no network.

The shape is the point: **every number on screen is produced by a plain function returning
plain data**, and the `st.*` calls only draw it. `summary_rows`, `headline`,
`progress_stages`, `worklist_rows`, `signal_rows`, `entry_panel` and `lookup_url` all take
a `Ledger` and give back dicts, so what the reviewer will see is assertable without a
browser. A dashboard whose correctness can only be checked by looking at it is a dashboard
nobody checks.

Nothing outside my lane is touched. `dashboard/` imports `src.contract` and `src.settings`
and nothing else — no pipeline, no resolvers, no judge.

## Anything I was unsure about

1. **The counts guard cannot fire through the current contract, so its test needs a
   subclass.** `Ledger.summary_counts()` walks the entries, so it always sums to
   `len(entries)` — `counts_are_consistent()` is unfalsifiable for any ledger you can
   actually construct. I kept the guard (my brief asks for it, and it is real defence
   against a fifth status, a cached count, or a half-written ledger from a crashed run)
   and tested it with a `CorruptedLedger` subclass that overrides one method. Defence that
   has never been fired is not defence. Say so if you would rather the guard came out.
2. **The judge chip reads its model from the ledger, not from `config.yaml`.** Config says
   which model we *meant* to call; `Verdict.judge_model` says which one *answered*. When
   the gateway is down those differ, and the strip should show the truth — there is a
   warning banner when any verdict came off a fallback rung. Mixed runs read "2 models"
   rather than silently picking the first.
3. **The last-resort lookup link is a Google Scholar title search.** Everything above it in
   the waterfall reshapes an identifier that is already present (provider URL → DOI →
   arXiv id). A title search invents nothing and is genuinely the next thing a human would
   do, but it is the one link that is not the record itself, so it is labelled "search for
   the title" rather than "open".
4. **Sidebar ledger picker globs `data/output/*.json`,** which does not exist yet. The
   committed fixture is always appended to the list so a fresh clone still renders — R5.
   If P6 writes somewhere else, that glob is one line.
