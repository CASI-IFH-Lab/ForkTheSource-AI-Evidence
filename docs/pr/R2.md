# R2-MINIMAL — the eval harness, `--fixtures` only

```bash
python eval/run_eval.py --fixtures <ledger.json> [<ledger2.json> ...] [--labels-dir eval/golden]
```

Scores any Ledger JSON on disk against the golden labels. Exit code **is** the release
gate: `0` clean, `1` a gate failed (D-019), `2` a hard error — a `ref_id` join gap (D-026)
or an unreadable label file. Offline; no network, no key.

`--full`, the worklist assertion, determinism, latency and `report.py` are REPLAN §4 cuts,
not stubs — Phase 2 row 1.

## Two divergences, logged as OBJECTION not as new D-numbers (REPLAN §6)

1. **False alarm is implemented as label divergence** — observed `needs_check` where the
   label expected `verified` — not `FORMAT.md`'s "`needs_check` on `injected: false`".
   Under FORMAT's wording the control's `R17`/`R18` duplicate pair, which is
   `injected:false` and *labelled* `needs_check` per D-016, reads as two false alarms on a
   paper with nothing wrong with it. They match their label, so they are counted as
   matches and printed on their own line.
2. **Label lookup tolerates a `.pdf` suffix** on `document_name` (`paper1.pdf` →
   `paper1.json`). D-025 says `document` matches `Ledger.document_name`; the Phase 1
   labels read `paper1` and no P6 ledger is on main to confirm against. Both spellings
   resolve rather than one becoming a missing-label hard error at the worst moment.

## `eval/golden_fixtures/` is new, and is not corpus

`eval/golden_fixtures/fixture-paper.json` labels the synthetic 8-entry fixture ledger. It
sits outside `eval/golden/` deliberately: that directory is the corpus, `validate_golden.py`
globs it, exactly one file in it may be `control: true`, and its `defect_id`s are globally
unique. The file carries a `_note` block saying all of this, uses the unallocated `D9x`
`defect_id` range, and keeps every `conflict` row `injected: true` so the harness cannot
fail its own gate on its own test data. The loader ignores top-level keys prefixed with
`_` and still hard-errors on every other unrecognised key.
